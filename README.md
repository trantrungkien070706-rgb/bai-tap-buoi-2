## Các lệnh Git cơ bản đã học:

1. **Lệnh Pull (Cập nhật code từ server về máy):**
   - Lệnh: `git pull origin dev`
   - Tác dụng: Kéo các thay đổi mới nhất từ nhánh `dev` trên GitHub về máy cá nhân.

2. **Lệnh Merge (Gộp nhánh):**
   - Lệnh: `git merge <tên_nhánh>`
   - Tác dụng: Kết hợp lịch sử và mã nguồn từ một nhánh khác vào nhánh hiện tại.

3. **Cách tải dự án từ GitHub về máy (Clone):**
   - Lệnh: `git clone https://github.com/trantrungkien070706-rgb/bai-tap-buoi-2.git`
   - Tác dụng: Tạo một bản sao của kho lưu trữ (repository) từ GitHub về máy tính.
